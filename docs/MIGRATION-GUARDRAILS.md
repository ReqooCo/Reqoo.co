# Migration Guardrails

## SHOP

The existing SHOP experience is the baseline. Preserve all existing products, images, categories, variants, pricing rules, promotion behavior, cart/checkout behavior and customer-facing flows. Upgrade structure, performance, security and UI without removing existing functionality.

## SIM

The existing PKSK simulator is the baseline. Preserve the current simulator UI, question flow, timer, audio, progress, access/license flow, payment/referral/admin behavior and assets. Improvements must be additive unless an existing bug requires a targeted fix.

## Rule

No broad frontend replacement during migration. First inventory the existing feature set, then refactor/move it one piece at a time with regression checks.
