Admin Security

Password/token Admin digunakan sebagai satu sesi untuk semua halaman Admin. Tetapkan atau tukar di sini.

Token ini mesti sepadan dengan token Admin yang ditetapkan pada backend/Cloudflare. Selepas disimpan, halaman SIM, SHOP dan halaman Admin lain menggunakan sesi yang sama — tak perlu masukkan password lagi setiap kali berpindah halaman.
