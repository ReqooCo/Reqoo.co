# Shop Visuals

Visual controls planned for the Admin Shop Visuals page. Uploads use the existing `/api/admin/media` endpoint and are stored as browser visual mappings for the current site. Hero supports separate desktop and mobile images.

## Controls
- Hero Desktop
- Hero Mobile
- Plaque Kayu
- Wood Clock
- Acrylic Brooch
- Fiber Laser
- 3D Print
- Personal Collection
- New & Special
- Promo Banner
- About / Brand
