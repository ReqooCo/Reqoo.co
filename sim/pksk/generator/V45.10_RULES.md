# REQOO PKSK Generator V45.10 — Production Rules

## Locked structure
- 50 sets target.
- Every set: Bahagian A = 30, Bahagian B = 70, Bahagian C = 3 writing choices.
- New sets are generated from zero; legacy question text is not reused.

## Bahagian A — hard QA gates
1. Include situational judgement and SSQ-style items, with varied contexts.
2. Do not make the keyed answer obviously identifiable because it is the longest option.
3. If the correct option is clearly longer than every distractor by more than 8 characters AND more than 2 words, HARD FAIL and regenerate/rephrase naturally.
4. Do not mechanically shorten a correct answer just to pass the length check.
5. Distractors must remain plausible and grammatically natural.
6. Rotate correct-option positions; do not create predictable answer-position patterns.
7. Avoid repeated scenario templates, openings and context nouns across sets.
8. Duplicate stem or near-duplicate context inside a set is a hard fail.

## All sections
- Exactly 100 objective questions + 3 writing choices.
- Unique IDs within each set.
- Post-generation QA is mandatory before production publication.
- Any failed hard gate blocks publication; never bypass a failed gate.
- Mathematical questions may use visual data when useful and should retain appropriate higher difficulty.
- Writing choices must be distinct and suitable for rubric-based simulation scoring.

## Publication contract
A set may only be copied into `sim/pksk/simulator/sets/SET 01-10/data/` after the complete QA pass reports PASS. Temporary generator/build files must be removed after successful publication.
