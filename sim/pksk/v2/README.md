# REQOO PKSK Simulator V2

Foundation branch: rebuild/pksk-v2.

The simulator uses the existing CBT engine architecture: 50 sets, JSON question-bank loading, 90-minute timer, answer persistence, question navigation, flagging, scoring, and Bahagian C writing flow.

Question content remains data-driven under `sets/`; do not replace the locked Set 01 baseline without explicit approval.
