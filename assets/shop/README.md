# SHOP Product Images

Place product images here using these editable filenames:

- `plaque.webp`
- `brooch.webp`
- `medal.webp`
- `trophy.webp`
- `3d-print.webp`

The catalogue points to these paths. If a real product photo is uploaded later, replace the image file without changing the product/order code.

AI-generated placeholders may be used temporarily, but they must be clearly treated as placeholders until replaced by the actual product photography.
