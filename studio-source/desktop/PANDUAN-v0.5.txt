REQOO 3D STUDIO 0.5.0 — PREMIUM WORKSPACE
Windows 10/11 x64

KEMAS KINI UTAMA
- UI cerah yang lebih kemas; tetapan tipografi, ketebalan, warna dan alat tambahan boleh dilipat.
- Panel edit kanan hanya muncul apabila huruf/objek dipilih. Klik × atau Esc untuk tutup.
- Drag objek terus pada canvas untuk bergerak pada satah X/Y. Nilai Z dikekalkan.
- Drag ruang kosong untuk putar kamera. Mod Putar (O) membolehkan putaran kamera di atas objek juga.
- Kotak sorotan menunjukkan objek dipilih. Undo/redo menyimpan sehingga 30 tindakan semasa sesi.

SHORTCUT
Ctrl+Z                 Undo / kembali
Ctrl+Y atau Ctrl+Shift+Z  Redo
Ctrl+X                 Cut objek
Ctrl+C                 Copy objek
Ctrl+V                 Paste objek
Ctrl+D                 Duplicate objek
Delete / Backspace     Buang objek dipilih
Ctrl+S                 Simpan projek
Ctrl+O                 Buka projek
Esc                    Tutup panel dan nyahpilih
V                      Mod gerak objek
O                      Mod putar kamera
F                      Muatkan produk dalam pandangan
Anak panah             Gerak objek 1 mm
Shift + anak panah     Gerak objek 5 mm
Shift semasa drag      Snap kedudukan kepada 1 mm

Shortcut edit objek tidak dijalankan semasa menaip dalam input, supaya cut/copy/paste/undo teks kekal berfungsi biasa. Ctrl+S dan Ctrl+O boleh digunakan ketika menaip. Copy/paste objek ialah clipboard dalaman aplikasi, bukan antara aplikasi lain. Duplicate menghasilkan objek bebas, tidak terikat kepada susunan teks asal. Sejarah undo tidak disimpan dalam fail JSON.

PRODUK SEDIA ADA
Keychain huruf/nama; nametag 75 × 25 mm dengan petak stiker Jata dan bingkai resin sekeliling SELURUH nametag; keychain mini gaya plat biasa dan EV. Jata tidak dicetak 3D. Semua ukuran dan fungsi font versi 0.3 dikekalkan.

ALIRAN KERJA
Pilih produk, taip nama/nombor, pilih font dan Jana reka bentuk. Klik huruf untuk membuka panel kanan, atau drag untuk mengubah kedudukan. Gunakan Buka/Simpan/Eksport STL pada bar atas. Senarai objek dan alat import berada dalam kumpulan boleh lipat di kiri. Selepas mengubah jenis font atau parameter produk, Jana reka bentuk membina semula produk dan menggantikan edit semasa; gunakan Undo jika perlu kembali.

FONTS / CETAKAN
Font Windows yang dipasang dan import TTF/OTF disokong. Untuk jana semula menggunakan font tersuai selepas membuka projek dalam sesi lain, buka semula fail font asal; bentuk huruf tersimpan masih boleh disunting tanpa font itu.
STL tidak menyimpan warna. Eksport tapak/huruf atau objek dipilih secara berasingan; kekalkan koordinat apabila mengimport bersama ke slicer. Model tidak menjalankan boolean union/repair automatik. Semak slicer dan cuba satu cetakan dahulu. Bingkai resin awal 1.5 mm di atas tapak, huruf 1.2 mm, petak stiker 18 × 18 mm dengan lekuk 0.3 mm; semua parameter tersebut boleh dilaras.

PEMASANGAN
Tutup versi lama dan jalankan installer 0.5.0 pada folder pemasangan yang sama. Simpan projek sebelum kemas kini. Versi portable: Extract All, kemudian buka Reqoo 3D Studio.exe bersama fail lain dalam foldernya.
Windows 11 x64 diuji. Windows 10 belum diuji terus; EXE belum ditandatangani. Rujuk rekod ujian untuk batas ujian pemasangan registry/Start Menu.

KEMAS KINI 0.5.0
UI cerah dengan panel tersusun dan ruang kerja berinspirasikan Bambu Studio.
Lengkung geometri dipertingkat: lubang bulat 192 sisi, teks 48 segmen lengkung.
STL tidak menyimpan warna. Gunakan 3MF warna atau Buka di Bambu Studio.
Dalam Bambu: semak saiz mm, padankan warna dengan filament/AMS, pilih printer,
kemudian Slice plate dan Print plate. Aplikasi ini tidak menghantar arahan cetak sendiri.
Butang Bambu menyimpan salinan 3MF dalam folder data aplikasi/Bambu Export.
Jika Bambu tidak dikesan, eksport 3MF dan buka fail itu secara manual.
Import 3MF standard mungkin memerlukan pemadanan warna filament secara manual.
Projek JSON/STL lama mengekalkan mesh lama. Simpan salinan projek, kemudian jana
semula reka bentuk untuk lengkung baharu. Jana semula menggantikan suntingan manual.
Ujian automatik mengesahkan warna dan unit 3MF; cetakan fizikal tidak diuji.
